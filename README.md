# Parvez Hasan - Portfolio
live link : [https://protfolio-parvez-hasan.netlify.app/]

A modern, responsive portfolio website built with React.js, featuring smooth animations with Framer Motion and GSAP.

## Features

- ⚡ Built with React.js and Vite
- 🎨 Styled with Tailwind CSS
- 🌙 Dark mode support
- ✨ Smooth animations with Framer Motion
- 🎭 Advanced scroll animations with GSAP
- 📱 Fully responsive design

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```

## Technologies Used

- React.js
- Vite
- Tailwind CSS
- Framer Motion
- GSAP
- Material Symbols Icons
